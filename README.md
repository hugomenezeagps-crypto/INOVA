# Vencer com Visão

Plataforma digital de autoajuda para a empresa **Vencer com Visão**, desenhada como um programa guiado de mudança de vida em 40 dias. A experiência combina tarefas diárias, vídeos motivacionais, dicas práticas e um sistema de pontuação para acompanhar a evolução.

## Recursos principais

- ✅ **Plano estruturado em 40 dias** dividido em quatro fases temáticas com foco crescente.
- ✅ **Tarefas diárias** interativas com controle de conclusão e sincronização com o sistema de pontuação.
- ✅ **Pontuação dinâmica** com barra de progresso e contagem de missões completadas.
- ✅ **Vídeos motivacionais** selecionados para cada dia do plano.
- ✅ **Afirmações e dicas práticas** para reforçar a mentalidade e orientar ações concretas.
- ✅ **Diário de reflexão** com salvamento local das anotações de cada dia.
- ✅ **Persistência de dados** via `localStorage`, permitindo continuar de onde parou.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo [`index.html`](index.html) diretamente no navegador (Chrome, Firefox, Edge, etc.).
3. Salve o atalho na tela inicial do celular ou mantenha o site aberto no navegador para acompanhar o plano diariamente.

> Nenhuma dependência adicional é necessária: todo o conteúdo estático está incluído nos arquivos `HTML`, `CSS` e `JavaScript` deste repositório.

## Estrutura

```
.
├── index.html   # Estrutura base da plataforma
├── style.css    # Estilos visuais e responsividade
└── script.js    # Dados do plano, lógica de pontuação e interatividade
```

## Personalização

- Adicione novos vídeos substituindo os links do YouTube em `script.js`.
- Altere tarefas, dicas ou afirmações ajustando os objetos do plano.
- Ajuste cores e tipografia através das variáveis em `style.css`.
